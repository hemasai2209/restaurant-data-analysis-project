# restaurant-data-analysis-project
Exploratory Data Analysis project using Python



## Project Overview
This project performs exploratory data analysis (EDA) on a restaurant dataset containing 9500+ restaurant records.

The analysis focuses on:
- Cuisine trends
- City-wise restaurant distribution
- Price range analysis
- Online delivery impact
- Geographic distribution
- Votes vs Ratings correlation

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Affordable restaurants dominate the dataset.
- Restaurants offering online delivery generally have higher ratings.
- Restaurant distribution is concentrated in metropolitan regions.
- Customer votes show a positive relationship with ratings.
